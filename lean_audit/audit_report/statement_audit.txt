Do the paper’s claims match Lean?
Statement audit of body.tex
18 October 2026      •    42 Lean source files, 6,632 lines

Verdict
The main mathematical results are substantially aligned. Each of the paper’s 13 labelled theorems, lemmas,
and corollaries has a corresponding Lean result, with explicit constants for the bounds hidden by ≲k . The
backward construction, exact Lanczos output, localization, containment, and the Lipschitz spectral-measure
estimate are supported by actual proofs.
The paper does not fully match as written. Its divided Ritz-residual inequality omits a nonzero-vector
hypothesis that the Lean theorem explicitly requires. A permitted run can have Vk y = 0 for a unit eigenvector y
of Tk . The general commutator bound also needs an empty-maximum convention at k = 1. The claim that Lean
proves “all of the statements in this paper” is too broad for this source tree.

Termination is handled, with a choice of auxiliary vector
Paper lines 195–259 allow βk = 0 and set the unformed vk+1 = 0. Lean does not require that terminal raw
vector to be zero; it is used multiplied by βk where needed. This weakens the assumptions and causes no conflict
for the paper’s run.
For the backward construction the paper allows any unit v̄k+1 and sets dk+1 = 1 (line 677). Lean makes the
specific permitted choice v̄k+1 = v1 / ∥v1 ∥ in normalizedVec (Lanczos/Normalized/Normalization.lean, line 138).
The packaged run theorems therefore certify that choice. The generic dilation algebra is parameterized by
matrices and supports the paper’s construction, but there is no packaged run-level theorem quantifying over
every terminal unit-vector choice. For literal correspondence, specify the same choice in the paper or generalize
the run-level interface.
GreenbaumBackwardModel.exact_next deliberately assumes βk > 0. The theorem unconditionally reproduces Tk ,
βk , and the first k exact vectors; it does not identify an auxiliary unit vector with an exact Lanczos output after
termination. This agrees with the stated output claim in thm:greenbaum. The final sentence of its proof (line
954) should be read with this distinction.

Small indexing clarification in the generic commutator lemma
At k = 1, max1≤i<k βi |γi+1 − γi | is a maximum over an empty set. The paper gives no convention. Lean’s
defectJump (Core/SaadGramCommutator.lean, line 40) inserts zero at the final index and takes a maximum over a
nonempty Fin k. Consequently this term is zero when k = 1. State that convention, and write the lower index
limits explicitly. Lean uses |Ti,i+1 (γi+1 − γi )|; this equals the printed expression because the paper’s internal βi
are positive. If the lemma is restated for arbitrary signed off-diagonal entries, keep the absolute value on the
coefficient. Also make 1 ≤ k ≤ kmax explicit in the setup.

6. Coverage limits and recommended wording
The “all statements” claim is not supported literally
Paper line 102 says that formal Lean proofs are supplied for all statements. The source tree supports the
numbered analytic results described in this report, subject to the qualifications above, but does not contain all
of the following:

• A formal execution semantics for Algorithm 1, an IEEE arithmetic model, or a theorem constructing LanczosRun
  from an execution of that algorithm. The kernel bounds and normalization properties are hypotheses, as the
  paper’s assumption-based analysis intends.
• A theorem relating the given original starting vector to the first computed vector through the initial
  normalization perturbation (lines 190–193). The run model starts with its stored near-unit v1 .
• A general theorem that exact Lanczos on an arbitrary symmetric input produces an orthonormal Krylov
  basis, including the span equality in lines 24–30. Core/ExactLanczos.lean defines a process and identifies its
  outputs given an orthonormal recurrence; its structure OrthonormalRecurrence assumes orthogonality. This is
  sufficient for the backward theorem, where orthogonality is independently proved by dilation.
• Verification of the numerical values, cluster counts, or weight errors in the figures and numerical illustration
  (lines 41–44, 603–608, 1043–1062). There is no instantiation of the Lean model with those experiment data.
• Proofs of historical comparisons, claims about practical accuracy, or statements about the precision needed
  for kernels and downstream algorithms. Those require their own evidence; they are not consequences certified
  by the current project merely because they occur in the paper.

Suggested replacement for line 102:

      The accompanying Lean development proves counterparts of the main local-error, Gram-commutator,
      loss-of-orthogonality, backward-model, localization, containment, and Lipschitz spectral-measure
      results, with explicit constants, for runs satisfying the stated arithmetic model. The implementation-
      to-model connection, introductory background results, and numerical experiments are not formalized.

Numerical illustrations need separate validation
The formal perturbation theorem is about the exact real matrices in its construction. Forming the model
in double precision, as described in the paper, introduces additional errors that the Lean theorem does not
bound. Likewise, double precision with full reorthogonalization is a numerical reference for exact Lanczos, not
an exact-arithmetic certificate (figure caption, line 42). The observed 4 · 10−6 weight agreement and 2.5 · 10−7
perturbation norm should be presented as experimental measurements.
The one-sided localization theorem does not by itself certify that each original eigenvalue has a cluster of exactly
k + 1 numerical model eigenvalues. Such a count needs a matching/separation argument or direct validated
numerical evidence. This audit makes no claim that the reported experiment is incorrect.

Documentation drift
lean/README.md, lines 30–31, says the nonzero condition on the divided Ritz residual appears in both paper and
code. It is present in the code but absent from this body.tex. The README also links to a correspondence map
and prior reports not supplied in this workspace. Those assertions were not used to establish the verdict.

Minimum changes to align the paper
Add the nonzero condition, define the empty defect-jump maximum, narrow the formalization claim, and
qualify the convergence sentence. For exact statement correspondence at termination, specify the same auxiliary
unit-vector choice as Lean. None of these changes requires weakening the proved main stability bounds.
